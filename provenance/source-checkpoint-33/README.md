# Marathi source checkpoint: 33/722

This directory freezes the machine-readable evidence for editable Marathi source
OLP-0004–OLP-0036: 33 units and 410 aligned translated content blocks. It is not
a reader release; `foundations-v0.2` remains the latest verified 16-unit reader.

Every translated block resolves to at least one recorded Marathi canon passage.
The evidence distinguishes preserved textbook/page-image hashes from short,
hash-pinned web observations for which origin HTML bytes were unavailable. The
OpenLogic source remains authoritative for mathematical definitions, formulas,
identifiers, citations and directionality.

`SOURCE_CHECKPOINT.json` inventories every translation and evidence file by byte
count and SHA-256. `SEGMENT_CANON_USE.jsonl` records actual passage and term use.
`PROVENANCE_REPAIR-MR-P034-20260904.json` records the manager audit that found and
repaired one previously empty segment citation and anchored the reduction heading
to an official Marathi glossary observation.
