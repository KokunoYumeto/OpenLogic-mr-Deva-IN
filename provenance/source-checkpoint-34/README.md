# Marathi source checkpoint: 34/722

This directory freezes the machine-readable evidence for editable Marathi source
OLP-0004–OLP-0037: 34 units and 416 aligned translated content blocks. It is a
source checkpoint; `foundations-v0.2` remains the latest verified public reader.

Every translated block resolves to at least one recorded Marathi canon passage.
The evidence distinguishes preserved textbook/page-image hashes from short,
hash-pinned web observations for which origin HTML bytes were unavailable. The
OpenLogic source remains authoritative for mathematical definitions, formulas,
identifiers, citations and directionality.

`SOURCE_CHECKPOINT.json` inventories every translation and evidence file by byte
count and SHA-256. `SEGMENT_CANON_USE.jsonl` records actual passage and term use.
The cumulative 34-unit development reader built twice to identical 48-page PDF
bytes with clean logs and passed an all-page visual inspection; it is not a new
release because the complete accessible HTML companion remains outstanding.

The shared OLSIZ-001–OLSIZ-007 corrections are applied and documented. The
attempted shared OLSIZ-011 finding was retracted as a false positive before any
Marathi target change; its exact byte evidence and tombstone hashes are preserved.
