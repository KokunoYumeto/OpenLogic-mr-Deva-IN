# Marathi source checkpoint: 65/722

This directory freezes machine-readable evidence for editable Marathi source
OLP-0004–OLP-0068: 65 units, 747 aligned translated content blocks, 56 reader
sections and eight complete chapters. The remaining 657 units are unfinished.

Every translated block resolves to at least one recorded Marathi canon passage.
Canon research is one unit ahead: MR-C069, MR-P092 and prospective term T171 are
preserved for OLP-0069, but that draft target has no aligned occurrences and is
excluded from both this checkpoint's translation inventory and the release archive.
The evidence distinguishes preserved textbook/page-image hashes from short,
hash-pinned web observations for which origin HTML bytes were unavailable.
OpenLogic remains authoritative for mathematical definitions and notation.

`SOURCE_CHECKPOINT.json` inventories every translation and evidence file by byte
count and SHA-256. It links the synchronized shared-schema decision bundle in
`../translation-decisions/`: readable full and priority views, one-row-per-
occurrence CSV, canonical JSON, the frozen schema and exact QA.

The cumulative reader passed two byte-identical guarded builds and visual review
of all 89 PDF pages. Its offline HTML companion preserves 3,521 native MathML
expressions, 13 diagrams with detailed Marathi alternatives, three semantic proof
figures with 11 formula rows, and 210 valid internal links. Desktop and 390-pixel
mobile Chromium review found no page-level overflow and verified contained proof-
table scrolling, local fonts and keyboard skip navigation. No independent human
linguistic review is claimed.
