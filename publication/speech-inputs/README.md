# सूत्रांचे मराठी श्राव्य वाचन

*संच, तर्कशास्त्र, संगणन* या पाठ्यपुस्तकाच्या सूत्रांचे उच्चार नव्या आवृत्तीशी जुळवण्यासाठी लागणारे स्रोत येथे दिले आहेत. वाचण्यासाठी [मराठी पाठ्यपुस्तकाची प्रकाशित आवृत्ती](https://github.com/KokunoYumeto/OpenLogic-mr-Deva-IN/releases/tag/slc-2026-11-16-r3) उघडा. [त्याच आवृत्तीचे श्राव्य स्रोत](slc-2026-11-16-r3.zip) तिच्या १०,५९२ सूत्रस्थळांशी जुळतात.

संग्रहातील `reader.html` ही उच्चार जोडण्यापूर्वीची HTML प्रत आहे. `speech-input.json` प्रत्येक सूत्राचा क्रम आणि संदर्भ नोंदवते. `speech-store.json` मध्ये मराठी उच्चार, संदर्भानुसार बदलणारी वाचने, वापराचे नियम व त्यांची संदर्भस्थळे आहेत. `occurrence-sources.json` मधून सूत्रस्थळांची स्रोतांशी जुळणी पाहता येते. `sources.json` मध्ये मूळ प्रकाशनाचा दुवा आणि फाइलींचे SHA-256 दिले आहेत.

नवी आवृत्ती तयार करताना संग्रह उलगडा. खालील आज्ञेतील `previous` हा त्या संग्रहाचा मार्ग आणि `new/reader.html` हा नव्या पाठ्यपुस्तकाचा उच्चार जोडण्यापूर्वीचा HTML मार्ग आहे.

```sh
python -m olpkit speech-sync --previous-reader previous/reader.html --previous-packet previous/speech-input.json --previous-store previous/speech-store.json --reader new/reader.html --out speech-update
```

सूत्राचा अर्थ किंवा संदर्भ बदलला असेल, तर इंग्रजी व मराठी एकके आणि संज्ञांचे संदर्भ पाहून त्याचे वाचन ठरवा. निर्णय लागू करताना `--previous-source-map previous/occurrence-sources.json` हा पर्याय वापरा.

मूळ पाठ्यपुस्तक Richard Zach यांचे आहे. विभागांचे श्रेय Open Logic Project आणि मूळ योगदानकर्त्यांना आहे. मूळ मजकूर व त्याचे मराठी रूपांतर CC BY 4.0 अंतर्गत आहेत. मराठी श्राव्य वाचने OpenAI Codex च्या GPT-6.1 Sol आणि GPT-6 Astra यांनी Ultra तर्कप्रयत्न वापरून तयार केली. स्वतंत्र मानवी पुनरावलोकनाचा दावा नाही.
