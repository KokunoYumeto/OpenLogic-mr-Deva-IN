# संपूर्ण मराठी आवृत्तीचा स्रोत-संग्रह

हा संग्रह तयार करण्यासाठी मराठी आवृत्तीचे Git भांडार वापरा. [ग्रंथ तयार करण्याच्या सूचनांनुसार](complete-source-mr.md) ७२२ एककांचा PDF, HTML आणि EPUB तयार करा. त्यानंतर भांडाराच्या मुख्य संचयिकेत ही आज्ञा चालवा.

```sh
python -X utf8 tools/package_complete_sources.py dist/03-openlogic-mr-complete-editable-sources.zip
```

या ZIP मध्ये इंग्रजी व मराठी एकके, संचयी LaTeX, ७९ स्वतंत्र प्रकरणांच्या LaTeX फाइली, अक्षररूपे, आकृत्या, परवाने आणि ग्रंथ पुन्हा तयार करण्यासाठी लागणारी साधने आहेत. ZIP रिकाम्या संचयिकेत उलगडा. त्यातील `README.md` प्रमाणे ग्रंथ पुन्हा तयार करा. दोन्ही आवृत्त्यांतील संचयी LaTeX, PDF, HTML मधील प्रत्येक फाइल आणि EPUB यांचे SHA-256 जुळतात का ते पाहा.

एककांची यादी व त्यांचे SHA-256 `units.jsonl` मध्ये आहेत. `publication/complete-source-inputs.json` मध्ये पूरक फाइली आणि छापील मजकुरात न येणाऱ्या संपादकीय टिप्पण्यांची नोंद आहे. अशा टिप्पणीचे शब्द बदलले असतील, तर तिचा नवीन मजकूर आधी वाचा. खूण आणि मूळ ओळीचा शेवट जतन करून फक्त संपादकीय नोंद वगळली जाते. गणिती स्पष्टीकरणे, संदर्भ, लेखकांची नावे आणि परवाने कायम ठेवा.
